求职简历蜕变引导

把招聘网站的真实岗位 JD，翻译成用户可执行的简历蜕变方案， 最终产出一份单文件可视化 HTML 引导页。 三级能力体系还算清楚哪些能力跨行业也值钱。

Python >=3.8 依赖 零第三方 许可 Apache-2.0 流水线 六步

三级能力体系 · 按「谁在验收」分，不按熟练度分

L1
垂类专属
验收方：行业内的人
技术方案落地 · 数据建模与指标口径 · 内容生产
L2
非垂类通用
验收方：通用管理标尺
结构化问题拆解 · 项目推进 · 书面表达
L3
跨类迁移
验收方：求职者自己
能力矩阵自评 · 岗位能力拆解 · 经历迁移改写
判定只问一句：这份证据的验收方是谁？
熟练度高 ≠ 层级高——十年资深文案的内容能力仍是 L1； 「跨 3 个行业协调过团队」仍是 L2。
L3 不打折——元能力没有相邻替代品，永远不适用迁移折价； 跨层同族能力按 0.6 折价计入迁移率。
三种场景都能跑：垂类精准求职 / 非垂类宽泛择业 / 跨行业转型。

快速开始

# 1) 获取
git clone https://github.com/NiuBi66666688/job-lailailai.git
cd job-lailailai

# 2) 验收（零依赖，不需要 pip install）
python verify.py

# 3) 装到本机 agent 平台
python scripts/install.py --detect
python scripts/install.py --target all --link

# 4) 算三级能力矩阵，再渲染一份引导页试试
python scripts/capability_matrix.py --profile examples/profile.sample.json \
       --jobs examples/jobs.sample.json --merge --out /tmp/jobs.json
python scripts/render.py /tmp/jobs.json out.html --theme sci
