# 学科轨道能力维度库

三条轨道，决定简历怎么写、项目怎么做、能力怎么提升。**文科绝不是「简化版理科」**。

判定方法：看用户专业。
- **sci 理工科**：计算机、电子、自动化、软件、人工智能、数学、物理、化学、生物、机械、材料、土木、医学
- **art 人文社科**：中文、新闻传播、外语、历史、哲学、法学、社会学、心理、教育、政治、图书情报、艺术设计
- **biz 经管商科**：工商管理、市场营销、会计、财务、金融、经济、国贸、人力、物流、电商、旅游管理

跨轨道情况（如「金融+计算机」）→ 取主修轨道，副修轨道维度作为**差异化亮点**写进简历。

---

## 一、理工科（sci）

| 维度 | 关键能力 | 可量化证据 |
| --- | --- | --- |
| 编程与工程 | 语言（Python/C++/Java/Go）、框架、版本控制、测试、部署 | 代码行数 / repo star / CI 通过率 |
| 算法与数据结构 | 复杂度分析、常见算法、刷题量 | LeetCode 题数 / 竞赛名次 |
| 专业领域深度 | 方向对应的核心理论（如 ML、分布式、编译、硬件） | 论文 / 复现结果 / 性能指标 |
| 系统与工具链 | Linux、Docker、K8s、云平台、数据库 | 部署过的服务 / QPS / 可用性 |
| 数据与实验 | 数据处理、统计、实验设计、A/B | 数据集规模 / 指标提升幅度 |
| 协作与开源 | Git 工作流、Code Review、开源贡献 | PR 被合并数 / issue 采纳 |
| 学习与迁移 | 快速上手新框架、读源码 | 从零到 demo 的周期 |

## 二、人文社科（art）

**核心认知：文科的「项目」不一定是代码。** 作品集、调研报告、策划案、翻译出版、
教案设计、数据新闻、政策建议书，都是有效且经常更强的证据。

| 维度 | 关键能力 | 可量化证据 |
| --- | --- | --- |
| 内容生产 | 选题、写作、编辑、结构化表达、多平台改写 | 篇数 / 阅读量 / 转载数 / 出版字数 |
| 传播与运营 | 平台规则、账号增长、活动策划、社群 | 粉丝增长 / 打开率 / 转化率 / GMV |
| 研究分析 | 文献综述、田野调查、访谈、问卷设计、质性/量化分析 | 样本量 / 报告页数 / 被采纳情况 |
| 数据叙事 | Excel/SPSS/Python/R 基础、可视化、图表表达 | 数据看板 / 可视化作品数 |
| 行业洞察 | 政策解读、行业研究、竞品分析、商业模式理解 | 研报篇数 / 被引用次数 |
| 沟通与协作 | 跨部门协调、对外沟通、会议组织、演讲 | 主导活动场次 / 参与人数 |
| 语言与工具 | 外语等级、CAT 工具、Office/飞书/Notion、基础 PS/PR | 证书等级 / 交付物数量 |

**文科简历的表达陷阱**：不要写「参与了 XX 项目」。要写
「独立完成 XX 篇深度报道，累计阅读量 XX 万，其中 X 篇被 XX 平台转载」。
即使用户没提供数字，也要用 `[待补充：阅读量/转化率/样本量]` 把量化的位置**逼出来**。

## 三、经管商科（biz）

| 维度 | 关键能力 | 可量化证据 |
| --- | --- | --- |
| 商业分析 | 行业研究、竞品分析、财务分析、建模 | 研报份数 / 模型复杂度 / 预测准确度 |
| 数据分析工具 | Excel 高阶、SQL、Python/R、Tableau/Power BI | 数据量级 / 看板数量 / 自动化程度 |
| 财务与会计 | 三张表、估值、成本核算、审计基础 | 证书（CPA/ACCA 科目） / 实操案例 |
| 营销与增长 | 用户画像、渠道投放、内容策略、私域 | ROI / 获客成本 / 转化率 / 增长幅度 |
| 项目管理 | 进度、预算、风险、干系人、敏捷/瀑布 | 项目规模 / 预算 / 按期交付率 |
| 咨询与结构化 | 拆解问题、MECE、假设驱动、PPT 表达 | 案例数 / 竞赛名次 / 商业计划书 |
| 证书与工具 | CFA/CPA/证券从业/基金从业、Wind/Bloomberg | 通过科目 / 使用时长 |

## 四、能力提升维度（用于第 3 步项目推荐与第 5 步路线图）

当用户技能有明显缺口时，按轨道给出**可执行**的提升动作，不要只说「多练习」。

### 理工科
- 刷题：LeetCode 按 topic 分类推进，目标 200–300 题覆盖高频题型
- 造轮子：手写一遍核心组件（如 RAG 检索、KV cache、简单解释器），比调库更能应对面试
- 开源贡献：从 good-first-issue 起步，目标是 PR 被真实合并
- 读源码：选一个 JD 点名的项目精读，产出技术博客

### 人文社科
- 作品集：把散落的文章/报告整合成一个可在线访问的作品集站点或 PDF
- 数据能力：补 Excel 高阶 + 基础 SQL/Python，能独立完成一份数据新闻或运营复盘
- 平台实操：亲手运营一个账号（哪怕 500 粉），拿到真实的增长曲线
- 案例拆解：每周精拆 1 个行业优秀案例，写成结构化笔记（选题-执行-结果-可复用点）
- 证书/考试：教资、CATTI、法律职业资格、公考，按目标岗位倒推

### 经管商科
- 行研：产出一份完整的行业研究报告（含市场规模测算与竞争格局）
- 建模：搭一个财务模型或商业测算模型，能跑敏感性分析
- 数据分析：把一个真实业务问题用 SQL + 可视化完整回答一遍
- 案例面试：练 30+ 个 case，形成自己的拆解框架
- 证书：按目标岗位选 CPA/CFA/证券基金从业，优先考报名门槛低的

## 五、给简历的「定位一句话」模板

按轨道给出**不同的**定位范式，这是简历摘要的开头，决定 HR 的第一印象。

- **sci**：`定位：会落地 <核心技术栈> 全链路、能用 <量化指标> 说话的 <方向> 工程师。`
- **art**：`定位：能独立完成从选题到分发的 <内容形态>，有 <量级> 真实传播/研究结果的 <方向> 候选人。`
- **biz**：`定位：能把 <业务问题> 拆成可执行方案、并用 <工具/模型> 验证的 <方向> 候选人。`
